# MYNRI360 – MASTER WEBSITE DESIGN PROMPT

## Project Overview

Create a world-class, premium, multinational corporate website for **MYNRI360**, a company that provides end-to-end assistance for Non-Resident Indians (NRIs) worldwide.

The website should feel like a combination of a luxury consulting company, premium concierge service, global corporate brand, and high-end technology company.

**This is NOT a local business website.**

Visitors should instantly feel:

* Trust
* Professionalism
* Premium Quality
* International Standards
* Fast Service
* Reliability
* Security
* Family Care
* Global Reach

The entire experience should be modern, elegant, dynamic, highly animated, and polished.

# WhatsApp Integration

When the user selects a service and clicks **"Get Assistance on WhatsApp"**, automatically generate a professionally formatted WhatsApp message.

Format:

```
Hello MYNRI360 Team,

I would like assistance with the following service.

Name:
Country:
Current City:
Phone:
Email:

Selected Service:
Preferred Date:
Preferred Time:

Message:

Please contact me at your earliest convenience.

Thank you.
```

If no service is selected:

```
Hello MYNRI360 Team,

I would like to know more about your NRI services.

Please contact me.

Thank you.
```

# Final Goal

Design **MYNRI360** as a **global premium NRI services brand** that looks comparable to multinational consulting firms. Every page must feature unique layouts, smooth transitions, premium animations, immersive interactions, and a polished visual identity that makes visitors feel confident entrusting MYNRI360 with their needs in India. The final result should be memorable, conversion-focused, highly responsive across all devices, and ready to scale as an international brand.
